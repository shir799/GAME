# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-11-13

### Added
- Initial release
- Core game engine with EventBus, GameLoop, and GameEngine
- Resource management system (money, cannabis, XP)
- Farm system with plant growth mechanics
- Upgrade system with multiple categories
- Quest system with tutorials and repeatable quests
- Police risk system with raids
- Idle/offline progress calculation
- Save/load system with LocalStorage
- Responsive UI with Tailwind CSS
- TypeScript type safety throughout
- Comprehensive test suite
- Full documentation (README, ARCHITECTURE)

### Core Features
- 8 different plant strains to grow
- 15+ upgrades across 6 categories
- 15+ quests including dailies
- Plant growth stages with modifiers
- Police heat and raid mechanics
- Offline progress (up to 8 hours)
- Auto-save functionality
- Save import/export

### Technical
- Vite build system
- TypeScript 5.3+
- Tailwind CSS 3.4
- Vitest testing framework
- ESLint + Prettier code quality
- Module-based architecture
- Event-driven design
- 60 FPS game loop
